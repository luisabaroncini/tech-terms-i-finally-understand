# tech-terms-i-finally-understand
Tech concepts explained from a marketer's point of view.
A growing collection of tech concepts explained from the point of view of a marketer working in a software house.

Not a technical documentation.

Not a developer's glossary.

Just things I had to understand because apparently "the backend" is not a place.

---

## Why this exists

I work in marketing and communication inside a software house.

Which means I regularly find myself in conversations involving:

- APIs
- databases
- Kubernetes
- deployments
- cloud infrastructure
- authentication
- Git
- things that "should be pretty simple"

So I'm documenting what I learn.

Mostly so I don't have to ask the same question three times.

## The format

Every concept gets explained in four ways:

**What I thought it was**  
The wrong assumption I started with.

**What it actually is**  
The technically correct explanation, in normal human language.

**Why marketing should care**  
Because technology eventually becomes a product, a promise, a website, a sales conversation or a customer problem.

**What I still don't understand**  
Because pretending to understand things is not the point of this repository.
